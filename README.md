# QA Templates

Templates QA réutilisables pour structurer les premières observations, les risques et les actions d'amélioration d'une équipe.

## Template disponible

- [Rapport d'étonnement QA](rapport-etonnement/README.md)

Le rapport d'étonnement est conçu comme une session de test exploratoire appliquée à l'organisation : on capture le regard neuf des premières semaines avant que les habitudes ne rendent certains problèmes invisibles.

## Utilisation rapide

1. Ouvrir le [template de rapport](rapport-etonnement/template-rapport-etonnement.md).
2. Cliquer sur **Raw** puis copier le contenu dans un nouveau fichier Markdown.
3. Remplacer les éléments entre crochets par les observations de la mission.
4. Partager les constats avec l'équipe avant de transformer les pistes en plan d'action.

## Principes

- Décrire des faits observables, pas des jugements.
- Distinguer l'étonnement, le risque, l'impact et l'action.
- Vérifier les hypothèses avec les personnes concernées.
- Préserver les informations confidentielles de la mission.
