# Rapport d'étonnement QA

Le premier template de la collection [QA Templates](../README.md).

Il permet de documenter les premières observations d'une mission QA, de faire émerger les risques et de prioriser des améliorations concrètes. D'autres templates QA seront ajoutés progressivement dans le dépôt.

## Comment l'utiliser

Le document peut être rempli progressivement pendant les premières semaines, puis relu avec l'équipe. Il ne s'agit ni d'un audit exhaustif ni d'un jugement de l'organisation existante.

Le format proposé suit cette logique :

> Étonnement -> Risque -> Impact -> Action

## Bonnes pratiques

- Noter les faits dès qu'ils sont observés.
- Ajouter le contexte nécessaire pour rendre chaque constat vérifiable.
- Formuler les risques en termes d'impact sur la qualité, le délai ou la continuité.
- Identifier les points à confirmer avant de proposer une action.
- Ne pas inclure de données sensibles, de secrets ou d'informations permettant d'identifier un client.
